# CHROMA · 색의 숲 튜토리얼

프로젝트 루트에서 `python main.py`로 실행합니다. Python과 pico2d가 필요합니다.
타이틀에서 게임 시작 → 새 게임을 선택하면 튜토리얼을 시작합니다.

`previews/ex.png`의 동선을 참고해 기존 사원 튜토리얼을 새 숲 맵으로 교체했습니다.
맵은 4096×1008이며 가로·세로로 스크롤합니다. 가장 왼쪽에서 회색 캐릭터로 시작합니다.
카메라는 캐릭터를 조금 늦게 부드럽게 따라가며, R 또는 실패로 시작점에 돌아갈 때는 즉시 이동합니다.
배경은 흑백 숲이며, 추가한 Tileset.png의 풀·흙·돌 타일을 흑백으로 배치합니다.
높은 벽은 돌, 바닥은 흙과 풀, 얇은 발판은 유적의 돌 선반으로 표현합니다.
돌·풀·꽃 장식은 지형 표면에 맞춰 배치하며 충돌과 기존 이동 동선은 유지합니다.
도면의 빨간 선은 이동 경로이므로 게임에 그리지 않습니다.
물은 새 시트의 물 3프레임과 tileset_water.webp를 사용합니다. 회색 고체는 정지하고 파랑을 받으면 원래 색으로 움직입니다.

## 조작

- **A / D**: 이동
- **SPACE**: 점프
- **S**: 현재 밟은 얇은 발판이나 덩굴 발판을 통과해 내려가기
- **좌클릭**: 110픽셀 이내의 대상에 색 부여 / 대상에서 색 회수
- **1 / 2 / 3**: 현재 보유한 색을 파랑 / 초록 / 노랑으로 변환
- **R**: 위치·보석·물·덩굴·낙수·등불·진행 상태 초기화
- **ESC**: 설정 메뉴

색을 가지고 있지 않을 때는 색 변환으로 새 색을 만들 수 없습니다.
장치에 색을 부여하면 캐릭터가 회색이 되고, 회수하면 해당 색의 캐릭터가 됩니다.
색이 들어 있는 대상에서 추출하려면 빈손이어야 하며, 빈 장치에는 호환되는 색만 줄 수 있습니다.
상호작용 애니메이션 없이 클릭 즉시 색이 바뀌며 이동·점프 동작을 유지합니다.
머리 위에 A/D → SPACE 안내가 표시되고, 얇은 발판 위에서는 S 안내가 표시됩니다.
이동·점프·내려가기를 실제로 수행하면 해당 안내가 사라집니다.

## 설정 화면

새 `image/ui/ui.png`의 채색된 메뉴판·돌기둥 프레임·파란 버튼으로 설정 화면을 구성합니다.
수정된 시트의 숲 그림과 밝은 버튼 색을 반영하며, 타이틀은 최신 title.png를 직접 사용합니다.
게임 중 메뉴판은 화면 중앙에 표시하며, 위에서부터 설정 → 저장 → 타이틀로 → 종료 순서입니다.
설정을 누르면 메뉴판이 사라지고 중앙의 설정 패널로 교체됩니다.
패널 안의 사운드·조작 버튼으로 페이지를 전환하고 되돌아가기로 중앙 메뉴판으로 돌아갑니다.
타이틀에서 설정을 누르면 왼쪽 메뉴 없이 설정 패널을 화면 중앙에 바로 표시합니다.
메뉴와 페이지 버튼에는 이름을 표시하며, 기본값·되돌아가기 버튼만 글씨를 넣지 않습니다.
글씨는 18픽셀 흰색이며 밝은 프레임 위에서도 읽히도록 얇은 어두운 테두리를 더합니다.
음향 설정의 배경음악·효과음 슬라이더는 클릭하거나 드래그하여 각각 0~100%로 조절합니다.
음량 바와 최대 음량의 손잡이가 모두 기둥 안쪽에 머물도록 폭을 줄였습니다.
창을 닫았다 열어도 실행 중 음량 값이 유지됩니다.
패널 맨 아래 두 버튼은 기본값(원형 화살표), 되돌아가기(왼쪽 화살표)이며 글씨 없이 배치합니다.
기본값으로 음량을 80%로 초기화하고, 되돌아가기로 오른쪽 패널만 닫습니다.
BGM 슬라이더는 현재 재생 중인 배경음악에, 효과음 슬라이더는 UI 클릭 소리에 즉시 적용됩니다.
게임 중 ESC는 오른쪽 패널을 먼저 닫고, 메뉴에서 다시 누르면 게임을 계속합니다.
타이틀의 설정에서는 되돌아가기 또는 ESC로 타이틀로 돌아갑니다.
삭제된 보석 이미지 대신 파란 정사각형 색 공급원을 그리며, 추출하면 회색 정사각형으로 바뀝니다.

## 배경음악

- 타이틀: `sound/sound/title_bgm/placidplace-fantasy-lucid-forestpart-two-49992.mp3`
- 튜토리얼: `sound/sound/bgm/stage_1.mp3`

스테이지 1은 BGM 슬라이더 값에 0.25배 음량을 적용합니다.
기본 설정(80%)의 소리는 이전 버전에서 BGM 슬라이더를 40%로 맞췄을 때와 같습니다.

각 음악은 반복 재생됩니다. 새 게임의 로딩이 끝나 화면이 나타날 때 튜토리얼 음악으로 전환하고,
타이틀로 돌아가면 타이틀 음악으로 전환합니다. 설정창을 열거나 R로 초기화해도 곡을 다시 시작하지 않습니다.
음량은 화면 전환 후에도 유지되며, 종료할 때 음악을 정지하고 오디오 자원을 해제합니다.
타이틀·메뉴·설정의 활성 버튼을 좌클릭하면 `sound/sound/ui_sound/UI_Click_Soft_Wood_V02.wav`를 한 번 재생합니다.
버튼 위에 마우스를 올리거나 빈 곳·비활성 버튼을 누를 때는 소리를 재생하지 않습니다.

발소리·점프·착지·색 상호작용 효과음은 재생하지 않습니다. 기존 BGM과 UI 클릭 소리만 사용합니다.
`작은 잎사귀의 산들바람 애니메이션.gif`의 9프레임을 원래 색과 투명도를 유지해 타이틀 배경 위에 반복 재생합니다.
게임 맵에는 나뭇잎을 표시하지 않습니다.

## 진행 순서

1. 앞의 파랑 보석을 좌클릭해 파랑을 추출합니다.
2. 막고 있는 회색 물에 파랑을 부여하면 액체가 되어 통과할 수 있습니다.
3. 통과한 뒤 물에서 색을 회수하고 **2**로 초록으로 바꿉니다.
4. 첫 덩굴에 초록을 주고 생성된 발판을 점프로 올라 큰 지형에 도착합니다.
5. 첫 덩굴의 색을 회수하고 점프 구간을 건넌 뒤 얇은 발판에서 **S**로 내려갑니다.
6. 덩굴 1 → 덩굴 2 → 덩굴 3 순서로, 점프 중 이전 덩굴에서 색을 회수해 다음 덩굴에 부여합니다.
7. 마지막 덩굴에 초록을 둔 채 위쪽 끝까지 올라가 빈손으로 낙수의 파랑을 추출합니다.
8. 파랑을 잃은 낙수는 흑백 고체로 그 자리에 멈춥니다. 이를 밟고 마지막 쉼터로 점프합니다.
9. 낙수에서 얻은 파랑을 **3**으로 노랑으로 바꾸고 등불에 부여합니다.
10. 열린 문으로 내려가 가장 오른쪽 출구에 도착하면 완료됩니다.

덩굴은 초록을 부여하면 80픽셀 간격의 점프 발판이 생기고, 회수하면 사라집니다.
연속 덩굴 구간의 고정 쉼터 발판을 제거했습니다. 덩굴 끝에서 점프한 뒤 색을 회수·전달해야 합니다.
떨어져도 시작점으로 보내거나 기믹·색을 자동 초기화하지 않습니다.
마지막 덩굴의 낮은 발판(높이 176·256)을 제거해, 바닥에서 활성화하더라도 다시 올라갈 수 없게 했습니다.
이전 덩굴의 높은 발판에서 건너와 높이 336 이상의 발판을 밟아야 합니다.
다음 덩굴은 앞 덩굴의 윗부분에 도달한 뒤 사용할 수 있으며 화면 아래에 현재 안내가 표시됩니다.

낙수는 4개의 파란 사각형이 일정한 간격으로 내려옵니다.
**파랑 있음 = 움직이는 액체**, **파랑 추출 = 전체가 함께 멈춘 흑백 고체 발판**입니다.
어느 낙수에서든 파랑을 추출하면 네 개가 동시에 멈추며, 다시 부여하면 모두 다시 떨어집니다.
낙수의 고체 발판은 아래에서 통과해 위에 착지할 수 있습니다.
노랑 등불을 켜면 마지막 문이 열리고, 노랑을 회수하면 다시 닫힙니다.
