# 흑백 숲 횡스크롤 플랫포머

Python과 pico2d가 설치된 환경에서 프로젝트 루트의 `python main.py`로 실행합니다.
전체화면으로 시작하며 게임 화면 전체를 16:9 비율로 맞춰 표시합니다.
이미지 경로는 소스 위치를 기준으로 처리합니다.

- **A / D**: 왼쪽 / 오른쪽 이동
- **스페이스바**: 지면에서 점프 (키를 떼었다 다시 누르기)
- **S**: 공중에서 빠르게 내려오기
- **마우스 좌클릭**: 가까운 물에 파란색 전달 / 물에서 파란색 회수
- **R**: 캐릭터와 물의 색 및 위치 초기화
- **ESC** 또는 창 닫기: 종료

사원 맵과 다음 맵 전환을 제거하고 5,120픽셀 길이의 숲 맵 하나로 구성했습니다.
`previews/Free.png`의 전체적인 배치를 참고해 낮은 골짜기 → 숲 언덕 → 절벽 →
넓은 강 → 낮은 연못 → 숲 가장자리로 이어집니다. Free의 에셋은 사용하지 않습니다.
기존 정글 배경 5개 레이어가 서로 다른 속도로 스크롤합니다.

연결된 지형 내부에는 `Tile_12`, 드러난 면에만 이끼 가장자리를 사용합니다.
공중 발판 없이 연결된 지형의 높낮이를 점프로 넘어갑니다.
나무·덤불·풀·쓰러진 나무·자연석을 군집으로 배치하고,
실제 보이는 영역 전체가 평평한 마른 지면 안에 들어가도록 크기와 위치를 맞췄습니다.
오브젝트는 장식이며 밑면을 지면에 2픽셀 겹쳐 표시합니다.

물은 한 타일(32픽셀) 깊이이며 아래 바닥에 이끼 윗면 타일을 사용해 지면을 구분합니다.
폭포와 물보라는 제거했습니다. 배경·지형·장식은 흑백입니다.

파란색은 캐릭터와 물 전체를 통틀어 하나만 존재합니다. 시작 시 캐릭터가 파랑을 가집니다.
캐릭터에서 110픽셀 이내에 있는 물의 영역을 좌클릭하면 다음 상태로 전환합니다.

| 상태 | 캐릭터 | 클릭한 물 |
| --- | --- | --- |
| 시작 / 색 회수 후 | 파란색 원본 이미지 | 흑백, 애니메이션 없음, 밟을 수 있는 고체 |
| 색 전달 후 | `idle_gray.png` / `run_grey.png` / `jump_grey.png` | 원본 컬러, 움직이는 액체, 들어갈 수 있음 |

색을 주면 해당 물의 고체 충돌이 즉시 사라지고 캐릭터는 색을 잃습니다.
같은 물을 다시 좌클릭하면 색을 회수하며 물은 다시 굳습니다.
물 안에서 회수할 때는 캐릭터를 굳은 물 위로 올려 끼임을 방지합니다.
색을 물에 맡긴 동안 다른 흑백 물에는 색을 줄 수 없습니다.
물 밖 클릭, 범위 밖 클릭, 우클릭은 상태를 바꾸지 않습니다.
R 또는 추락 후 복귀 시 모든 물을 흑백 고체로 되돌리고 파랑을 캐릭터에게 반환합니다.

액체 물은 `GandalfHardcore Water Tiles sheet.png`의 3프레임 수면을 초당 6프레임으로 재생합니다.
액체 안에서는 바닥을 걸을 수 있으며 이동 속도는 70%이고 스페이스바로 나올 수 있습니다.

캐릭터는 idle 72×72, 달리기 80×80, 점프와 하강 84×84 크기로 표시합니다.
정지 시 idle 16프레임, 이동 키를 누르면 run 10프레임을 재생합니다.
벽에 막혀도 이동 키를 누르는 동안 run을 유지하고 위치만 멈춥니다.
점프 상승 중에는 jump의 앞 두 프레임, 하강 중에는 마지막 두 프레임을 반복합니다.
run과 jump는 오른쪽을 바라보는 원본을 기준으로 이동 방향에 맞춰 반전합니다.
흑백 달리기와 점프는 사용자가 추가한 `run_grey.png`, `jump_grey.png`를 직접 사용합니다.
몸과 머리의 충돌 범위는 64픽셀 정사각형의 투명 여백을 줄여 계산하고,
착지는 가운데 발 범위로 판정합니다. run 프레임별 실제 발 높이를 지면에 맞춰 표시합니다.

- 흑백 자산 생성: `python tools/make_grayscale.py` (Pillow 필요)
- 테스트: `python -m unittest discover -s tests`
- 미리보기 생성: `python tools/preview_levels.py` (Pillow 필요)

`previews/`에 구간별 PNG, 전체 배치 `forest_overview.png`, 색 전달·회수의 세 상태 PNG,
상호작용 애니메이션 `blue_transfer.gif`를 저장합니다.

사용 자산: GandalfHardcore FREE Platformer Assets (자연석·물).
