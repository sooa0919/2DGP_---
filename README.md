# 흑백 횡스크롤 플랫포머

Python과 pico2d가 설치된 환경에서 프로젝트 루트의 `python main.py`로 실행합니다.
전체화면으로 시작하며 게임 화면 전체를 16:9 비율로 맞춰 표시합니다.
이미지 경로는 소스 위치를 기준으로 처리합니다.

- **A / D**: 왼쪽 / 오른쪽 이동
- **스페이스바**: 지면에서 점프 (키를 떼었다 다시 누르기)
- **S**: 공중에서 빠르게 내려오기
- **E**: 출구 근처에서 `PRESS E`가 보이면 다음 맵으로 이동
- **ESC** 또는 창 닫기: 종료

첫 맵은 5겹의 정글 배경, 다음 맵은 4겹의 사원 배경입니다.
각 맵은 3,840픽셀 길이이며, 사원 출구는 첫 맵으로 다시 연결됩니다.
이끼 표면의 좌우 모서리, 흙 벽과 여러 내부 타일을 조합하고
계단식 오르막·내리막과 점프로 건너는 틈을 배치했습니다. 공중에 떠 있는 발판은 제거했습니다.
숲은 나무·쓰러진 나무·자연석 위주이며, 사원에는 비석·바위·석상을 배치했습니다.
오브젝트는 투명 여백을 제외한 실제 너비가 평평한 마른 지면 안에 들어가도록 배치하고,
밑면을 지면에 2픽셀 겹쳐 공중에 뜨거나 주변 지형을 뚫어 보이지 않도록 했습니다.
오브젝트는 장식이며 출구는 표지판으로 표시합니다.
발판에는 위·옆·아래 충돌을 적용하며 틈으로 떨어지면 해당 맵 시작점으로 돌아옵니다.
연결된 지형 내부에는 풀 가장자리가 없는 `Tile_12`를 사용하고 드러난 벽에만 가장자리를 둡니다.
각 맵의 물 웅덩이 3곳은 한 타일(32픽셀) 깊이로, 들어가서 바닥을 걸을 수 있습니다.
물속 이동 속도는 70%이며 스페이스바로 둑 위까지 점프할 수 있습니다.
반투명 물이 캐릭터 위에 겹쳐 보입니다.

캐릭터는 파란색 원본을 80×80 크기로 표시하고 정지 시 idle, 이동과 점프 시 run을 재생합니다.
왼쪽 위 맵 이름과 조작 안내는 표시하지 않으며 출구의 `PRESS E` 안내만 유지합니다.
배경·타일·기존 장식은 흑백이며 원본 이미지와 투명도는 보존합니다.
Fantasy Swamp Forest 오브젝트는 사용하지 않습니다.
지면에서 달릴 때 캐릭터 뒤쪽 발밑에 `SmokeFX Lite SpriteSheet 2A-2.png`의
6프레임 연기 애니메이션을 재생합니다. 방향에 맞춰 반전하며, 생성된 연기는 월드 위치에
남았다가 약 0.33초 뒤 사라집니다. 정지·공중·물속에서는 새 연기를 생성하지 않습니다.
Pillow가 설치된 환경에서 `python tools/make_grayscale.py`로 흑백 자산을 다시 생성합니다.

검증: `python -m unittest discover -s tests`

화면 미리보기: `python tools/preview_levels.py` (Pillow 필요).
두 맵의 시작·중간·물속·출구·좌우 달리기 화면을 `previews/`에 저장합니다.

사용 자산: GandalfHardcore FREE Platformer Assets (자연석과 석상), Smoke FX Lite (달리기 연기).
