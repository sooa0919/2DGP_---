# 정글 횡스크롤

Python과 pico2d가 설치된 환경에서 프로젝트 루트의 `python main.py`로 실행합니다.
이미지 경로는 소스 위치를 기준으로 처리하므로 다른 작업 폴더에서도 실행할 수 있습니다.

- **A / D**: 왼쪽 / 오른쪽 이동
- **W**: 바닥에서 점프 (다시 누르면 재점프)
- **S**: 공중에서 빠르게 내려오기
- **ESC** 또는 창 닫기: 종료

`background3_jungle2`의 5개 레이어를 순서대로 겹치고 이동 속도를 다르게 하여
가로 스크롤 시 배경에 깊이를 줍니다. `Tileset.png`의 이끼 표면과 흙 타일로
10화면 길이의 평평한 바닥을 구성했습니다.

캐릭터는 blue만 사용하며 64×64 크기로 표시됩니다. 정지하면 idle 16프레임,
이동하면 run 3프레임을 재생하고 좌우 방향에 따라 이미지를 반전합니다.
중력과 바닥 착지를 적용한 플랫포머 방식이며, 공중에서는 run을 재생합니다.
바닥, 화면 상단, 맵 양끝 밖으로는 이동할 수 없습니다.
