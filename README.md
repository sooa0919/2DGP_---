# CHROMA · 무너진 사원 튜토리얼

프로젝트 루트에서 python main.py로 실행합니다. Python, pico2d가 필요합니다.
전체화면 16:9로 시작합니다.

실행하면 추가한 title.png 타이틀 화면이 먼저 표시됩니다. 제목 아래 왼쪽에 게임 시작, 설정, 종료 버튼을 세로로 배치했습니다.
버튼은 title_select.webp의 위쪽 이미지를 기본으로 사용하고 마우스를 올리면 아래쪽 이미지로 바뀝니다.
게임 시작을 누르면 같은 위치에 새 게임, 불러오기가 표시되며 새 게임을 누르면 사원 튜토리얼이 시작됩니다.
하위 메뉴에서 ESC를 누르면 메인 메뉴로 돌아갑니다. 종료 버튼은 게임을 닫습니다.
설정과 불러오기는 현재 버튼 표시와 마우스 반응만 준비되어 있습니다.

새 게임을 누르면 타이틀이 0.6초 동안 검게 페이드아웃됩니다. 검정 화면 중앙에서 loading.gif의 12프레임 애니메이션을 재생하고, 아래에 `l`부터 `loading..`까지 타자 효과를 2번 반복합니다(약 2.9초).
이후 플레이 화면이 0.8초 동안 페이드인되며 조작이 시작됩니다. 전환 중에는 게임 진행과 플레이 입력을 멈추고 창 닫기는 계속 처리합니다.
GIF는 pico2d용 loading_frames.png와 프레임 시간 정보로 변환해 사용합니다. 원본을 바꾸면 `python tools/prepare_loading.py`로 다시 생성합니다(Pillow 필요).

현재 실행 화면은 11월 18일 수정한 프리뷰에 맞춘 흑백 타일 맵입니다.
배치를 16픽셀 격자에 맞추고 첫 번째 파랑 기믹을 연결했습니다.
캐릭터는 회색으로 시작하며 앞쪽 다이아몬드에서 파랑을 추출합니다.
다이아몬드는 diamond-01~05의 다섯 프레임을 초당 8프레임으로 반복합니다.
파랑을 가져오면 캐릭터가 파랑이 되고 다이아몬드는 회색이 됩니다.
시작 지점 오른쪽 바닥 구멍에는 폭포와 얕은 물웅덩이가 연결되어 있습니다.
물에 파랑을 주면 액체로 바뀌어 통과할 수 있고 회수하면 회색 고체로 굳습니다.
R 또는 낙사 후에는 캐릭터를 회색, 다이아몬드를 파랑, 물을 회색 고체로 되돌립니다.
맵 크기는 1792×672픽셀이고 시작 방의 바닥부터 천장까지는 144픽셀로 캐릭터 몸 높이의 약 2.3배입니다.
지형과 벽돌 배경, 목재 지지대는 main_lev_build 타일의 흑백 버전을 사용합니다.
머리 위 키 아이콘을 캐릭터에 가깝게 표시합니다.
검게 표시한 가로 발판은 아래에서 올라갈 수 있으며 위에서 S를 눌러 내려갑니다.
프리뷰의 높은 단차를 유지하여 현재 점프만으로 출구까지 연속 진행할 수는 없습니다.

## 조작과 학습

- A / D: 좌우 이동. 각각 두 번씩 새로 누르면 머리 위 키 아이콘 애니메이션이 끝납니다. 길게 누른 자동 반복은 세지 않습니다.
- SPACE: 지면에서 점프하면 점프 키 아이콘이 사라집니다.
- S: 얇은 발판 위에서 한 번 눌러 아래로 통과합니다. 다음 발판에서 다시 내려가려면 떼었다 누릅니다.
- 마우스 좌클릭은 110픽셀 이내의 다이아몬드 또는 물에 색을 전달하거나 회수합니다. 가능한 대상에 마우스를 올리면 아이콘이 깜박입니다.
- R: 스테이지, 색, 조작 학습 초기화. 일시정지 중에도 사용할 수 있습니다.
- ESC: 일시정지 / 계속하기. 종료는 창 닫기 또는 Alt+F4입니다.
- 현재 타일 맵에서는 색 설명창이 표시되지 않습니다.

키 조작은 텍스트 설명창 없이 아이콘 애니메이션으로만 안내합니다. 상단 왼쪽 구역 이름과 하단의 조작키·가까운 물 안내, 구역 진입 시 상시 설명은 표시하지 않습니다. 색 설명창은 색을 실제로 옮겼을 때만 표시합니다.

## 이전 색 기믹 구현 기록

previews/KakaoTalk_20261117_201407398.png의 시작 → 폭포 → 물 구간 → 낮은 통로와 높은 식물 구역 → 노랑 구역 → 출구 동선을 4096픽셀 길이로 구성했습니다.
사원 내부는 Tilesetv3의 벽돌, 석재, 부서진 기둥 타일만 사용합니다. 장식 오브젝트는 배치하지 않았습니다.
초록·노랑 구역에는 이동용 임시 계단이 있습니다. 실제 식물 생장·등불·봉인문·색 원천 오브젝트는 다음 배치 단계에 남겨 두었습니다.
시작 시에는 기존 구현처럼 플레이어가 파랑을 가지고 있습니다.

파랑은 PPT의 고체화 설명과 프리뷰의 필기가 서로 반대이므로 이번에는 프리뷰와 기존 코드를 따릅니다.
파랑을 주면 액체가 되어 통과하고, 회수하면 회색 고체가 되어 밟거나 벽으로 막힙니다.
좌클릭으로 주기와 회수를 모두 처리하는 기존 조작도 유지합니다.

폭포는 previews/스크린샷 2026-11-17 204340.png를 참고했습니다.
Animated Water Tiles 시트의 폭포 프레임과 아래 방향 텍스처 이동, 밑부분 물보라를 함께 그립니다.
폭포 아래는 석재를 낮춘 얕은 물웅덩이로 연결됩니다. 폭포와 물웅덩이는 하나의 색과 애니메이션 시간을 공유합니다. 흐르는 폭포는 불투명도 52%, 액체 수면과 물속은 55%로 캐릭터가 비쳐 보입니다. 색이 없는 폭포는 정지한 회색 벽입니다. 폭포 안에서 회수하면 가까운 옆으로 밀어내 천장 위로 튀거나 끼지 않게 합니다.

모든 한글 안내에는 추가된 fonts/Galmuri-v2.40.4/Galmuri11.ttf를 사용합니다. 해당 폰트의 SIL OFL 라이선스를 함께 보관합니다.
색 이동 설명은 파랑의 부여·회수 시 표시하며 초록은 생장, 노랑은 빛·봉인 해제로 설명합니다.
초록·노랑의 이동 후 설명은 장치 구현 시 같은 안내 시스템에 연결할 수 있습니다.
출구에 도착한 뒤 R로 다시 연습할 수 있습니다.
