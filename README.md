# 흑백 숲 횡스크롤 플랫포머

Python과 pico2d가 설치된 환경에서 프로젝트 루트의 `python main.py`로 실행합니다.
전체화면으로 시작하며 게임 화면 전체를 16:9 비율로 맞춰 표시합니다.
이미지 경로는 소스 위치를 기준으로 처리합니다.

- **A / D**: 왼쪽 / 오른쪽 이동
- **스페이스바**: 지면에서 점프 (키를 떼었다 다시 누르기)
- **S**: 공중에서 빠르게 내려오기
- **ESC** 또는 창 닫기: 종료

사원 맵과 다음 맵 전환을 제거하고 5,120픽셀 길이의 숲 맵 하나로 구성했습니다.
`previews/Free.png`의 전체적인 배치를 참고해 낮은 골짜기 → 숲 언덕 → 높은 물가와 폭포 →
넓은 강 → 낮은 연못 → 숲 가장자리로 이어집니다. Free의 에셋은 사용하지 않습니다.
기존 정글 배경 5개 레이어가 서로 다른 속도로 스크롤합니다.

연결된 지형 내부에는 `Tile_12`, 드러난 면에만 이끼 가장자리를 사용합니다.
공중 발판 없이 연결된 지형의 높낮이를 점프로 넘어갑니다.
나무·덤불·풀·쓰러진 나무·자연석을 군집으로 배치하고,
실제 보이는 영역 전체가 평평한 마른 지면 안에 들어가도록 크기와 위치를 맞췄습니다.
오브젝트는 장식이며 밑면을 지면에 2픽셀 겹쳐 표시합니다.

물은 한 타일(32픽셀) 깊이이며 들어가서 바닥을 걸을 수 있습니다.
물속 이동 속도는 70%이고 스페이스바로 물 밖으로 점프할 수 있습니다.
`GandalfHardcore Water Tiles sheet.png`의 3프레임 수면을 초당 6프레임으로 재생하고,
`GandalfHardcore Animated Water Tiles.png`의 20프레임 폭포와 물보라를 초당 10프레임으로 재생합니다.
절벽 위 물가에서 아래 강으로 폭포가 떨어집니다. 배경·지형·장식·물은 흑백입니다.

캐릭터는 파란색 원본을 72×72 크기로 표시하며 정지 시 idle, 이동과 점프 시 run을 재생합니다.
지면에서 달릴 때 뒤쪽 발밑에 Smoke FX Lite 2A-2의 6프레임 연기를 재생합니다.
정지·공중·물속에서는 새 연기를 생성하지 않습니다.

- 흑백 자산 생성: `python tools/make_grayscale.py` (Pillow 필요)
- 테스트: `python -m unittest discover -s tests`
- 미리보기 생성: `python tools/preview_levels.py` (Pillow 필요)

`previews/`에 구간별 PNG, 전체 배치 `forest_overview.png`,
폭포 애니메이션 `forest_waterfall.gif`를 저장합니다.

사용 자산: GandalfHardcore FREE Platformer Assets (자연석·물·폭포), Smoke FX Lite (달리기 연기).
