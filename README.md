# CHROMA · 색의 숲 튜토리얼

프로젝트 루트에서 `python main.py`로 실행합니다. Python과 pico2d가 필요합니다.
타이틀에서 게임 시작 → 새 게임을 선택하면 튜토리얼을 시작합니다.

`image/background/tile/stage1_preview.png`의 지형과 장치 위치를 사용하는 숲 스테이지입니다.
맵은 4096×1008이며 가로·세로로 스크롤합니다. 가장 왼쪽에서 회색 캐릭터로 시작합니다.
카메라는 캐릭터를 조금 늦게 부드럽게 따라가며, R 또는 실패로 시작점에 돌아갈 때는 즉시 이동합니다.
배경과 지형·나무·풀·바위는 모두 흑백이며, `image/background/tile/stage1_preview.png`의 상대 배치를 유지합니다.
프리뷰에서 물과 장치만 분리해 상태에 따라 다시 합치며, 같은 그림을 중복해서 겹치지 않습니다.
기존 반복 타일·임의 장식·사각형 장치 그림을 제거했습니다.
충돌은 새 그림의 흙바닥·절벽·윗가지·마지막 쉼터 윤곽에 맞췄습니다. 장식 나무·풀·바위는 통과합니다.
곡선은 4픽셀 간격으로 판정하며, 10픽셀 이하의 바닥 높이 차이는 걸어서 지나갑니다.
점프 속도는 원래 값인 560픽셀/초이며, 최대 점프 높이는 약 105픽셀입니다.
높은 지형 앞 두 곳에 초록색 덩굴 기믹을 임시 선·사각형으로 표시했습니다. 초록을 부여하면 80픽셀 간격의 발판이 활성화됩니다.
문 뒤 천장에 매달린 노란 원천과 마지막 천장의 파란 원천은 시작부터 원래 색으로 표시하며, 색을 추출하면 흑백으로 바뀝니다.
원본을 변경한 뒤에는 `python tools/prepare_stage.py`로 실행용 배경·장치·흑백 이미지를 다시 만듭니다.
폭포는 흑백일 때 정지한 고체이고, 파랑을 받으면 `water1.png → water2.png → water3.png` 순서로 0.22초마다 반복합니다.
파랑 물은 불투명도 45%로 캐릭터 앞에 그려 물속에서도 캐릭터가 비쳐 보입니다. 흑백 고체 물은 불투명하게 표시합니다.
물의 충돌·감속·클릭 판정은 폭포와 웅덩이 모양을 따르며, 주변의 빈 공간에는 적용하지 않습니다.
배경에 남은 세 폭포 프레임의 윤곽을 모두 제거하고 현재 프레임 한 장만 표시합니다. 파란 물의 불투명도는 30%입니다.
화면 아래 설명·조작 패널은 표시하지 않으며, 머리 위 키 안내와 보유 색 HUD는 유지합니다.
타이틀·UI·맵 그림은 선형 필터로 확대·축소합니다.
캐릭터·키 아이콘·픽셀 숲 배경은 픽셀 경계를 유지하는 필터를 사용합니다.

## 조작

- **A / D**: 이동
- **SPACE**: 점프
- **S**: 현재 밟은 얇은 발판이나 덩굴 발판을 통과해 내려가기
- **좌클릭**: 140픽셀 이내의 대상에 색 부여 / 대상에서 색 회수
- **1 / 2 / 3**: 현재 보유한 색을 파랑 / 초록 / 노랑으로 변환
- **R**: 위치·보석·물·덩굴·낙수·등불·진행 상태 초기화
- **C**: 충돌 범위 표시 켜기 / 끄기 (처음에는 꺼짐)
- **ESC**: 설정 메뉴

색을 가지고 있지 않을 때는 색 변환으로 새 색을 만들 수 없습니다.
충돌 표시 색은 빨강=고체 지형, 초록=내려갈 수 있는 발판, 파랑=액체 물 영역, 노랑=상호작용 대상, 하늘색=캐릭터입니다.
장치에 색을 부여하면 캐릭터가 회색이 되고, 회수하면 해당 색의 캐릭터가 됩니다.
색이 들어 있는 대상에서 추출하려면 빈손이어야 하며, 빈 장치에는 호환되는 색만 줄 수 있습니다.
상호작용 애니메이션 없이 클릭 즉시 색이 바뀌며 이동·점프 동작을 유지합니다.
머리 위에 A/D → SPACE 안내가 표시되고, 얇은 발판 위에서는 S 안내가 표시됩니다.
이동·점프·내려가기를 실제로 수행하면 해당 안내가 사라집니다.

## 설정 화면

새 `image/ui/ui.png`의 채색된 메뉴판·돌기둥 프레임·파란 버튼으로 설정 화면을 구성합니다.
수정된 시트의 숲 그림과 밝은 버튼 색을 반영하며, 타이틀은 최신 title.png를 직접 사용합니다.
게임 중 메뉴판은 화면 중앙에 표시하며, 위에서부터 설정 → 저장 → 타이틀로 → 종료 순서입니다.
설정을 누르면 메뉴판이 사라지고 중앙의 설정 패널로 교체됩니다.
패널 안의 사운드·조작 버튼으로 페이지를 전환하고 되돌아가기로 중앙 메뉴판으로 돌아갑니다.
타이틀에서 설정을 누르면 왼쪽 메뉴 없이 설정 패널을 화면 중앙에 바로 표시합니다.
메뉴와 페이지 버튼에는 이름을 표시하며, 기본값·되돌아가기 버튼만 글씨를 넣지 않습니다.
글씨는 18픽셀 흰색이며 밝은 프레임 위에서도 읽히도록 얇은 어두운 테두리를 더합니다.
음향 설정의 배경음악·효과음 슬라이더는 클릭하거나 드래그하여 각각 0~100%로 조절합니다.
음량 바와 최대 음량의 손잡이가 모두 기둥 안쪽에 머물도록 폭을 줄였습니다.
창을 닫았다 열어도 실행 중 음량 값이 유지됩니다.
패널 맨 아래 두 버튼은 기본값(원형 화살표), 되돌아가기(왼쪽 화살표)이며 글씨 없이 배치합니다.
기본값으로 음량을 80%로 초기화하고, 되돌아가기로 오른쪽 패널만 닫습니다.
BGM 슬라이더는 현재 재생 중인 배경음악에, 효과음 슬라이더는 UI 클릭 소리에 즉시 적용됩니다.
게임 중 ESC는 오른쪽 패널을 먼저 닫고, 메뉴에서 다시 누르면 게임을 계속합니다.
타이틀의 설정에서는 되돌아가기 또는 ESC로 타이틀로 돌아갑니다.
삭제된 보석 이미지 대신 파란 정사각형 색 공급원을 그리며, 추출하면 회색 정사각형으로 바뀝니다.

## 배경음악

- 타이틀: `sound/sound/title_bgm/placidplace-fantasy-lucid-forestpart-two-49992.mp3`
- 튜토리얼: `sound/sound/bgm/stage_1.mp3`

스테이지 1은 BGM 슬라이더 값에 0.25배 음량을 적용합니다.
기본 설정(80%)의 소리는 이전 버전에서 BGM 슬라이더를 40%로 맞췄을 때와 같습니다.

각 음악은 반복 재생됩니다. 새 게임의 로딩이 끝나 화면이 나타날 때 튜토리얼 음악으로 전환하고,
타이틀로 돌아가면 타이틀 음악으로 전환합니다. 설정창을 열거나 R로 초기화해도 곡을 다시 시작하지 않습니다.
음량은 화면 전환 후에도 유지되며, 종료할 때 음악을 정지하고 오디오 자원을 해제합니다.
타이틀·메뉴·설정의 활성 버튼을 좌클릭하면 `sound/sound/ui_sound/UI_Click_Soft_Wood_V02.wav`를 한 번 재생합니다.
버튼 위에 마우스를 올리거나 빈 곳·비활성 버튼을 누를 때는 소리를 재생하지 않습니다.

발소리·점프·착지·색 상호작용 효과음은 재생하지 않습니다. 기존 BGM과 UI 클릭 소리만 사용합니다.
`작은 잎사귀의 산들바람 애니메이션.gif`의 9프레임을 원래 색과 투명도를 유지해 타이틀 배경 위에 반복 재생합니다.
나뭇잎은 2304×1296 크기로 Lanczos 보간해 가장자리를 부드럽게 만들고, 3×3 시트의 프레임마다 투명 여백을 둡니다.
전체화면에서는 선형 필터를 명시적으로 적용합니다. 원본 GIF의 모양·색·9프레임·재생 간격은 유지합니다.
게임 맵에는 나뭇잎을 표시하지 않습니다.

## 진행 순서

앞의 파란 정사각형에서 색을 얻어 폭포에 부여하면 통과할 수 있습니다.
색을 회수하고 2로 초록으로 변환하면 그림의 덩굴 발판을 활성화할 수 있습니다.
활성 덩굴 발판은 아래에서 통과해 위에 착지하며 S로 내려갑니다. 회수하면 발판 판정이 사라집니다.
그림 중앙의 문 장치는 노랑으로 작동하며, 색을 회수하면 문이 닫힙니다.
이전 맵의 사각형 낙수와 보이지 않는 진행 잠금은 새 스테이지에서 사용하지 않습니다.

마지막 두 덩굴 사이의 발판은 엘리베이터입니다. 오른쪽 아래 꽃 모양 장치에 노랑을 부여하면
높이 172에서 827까지 초당 130픽셀로 올라가고, 장치에서 색을 회수하면 내려갑니다.
움직이는 중 취소하거나 재활성화하면 현재 위치에서 방향을 바꿉니다.
발판의 그림과 충돌이 함께 움직이며 탑승한 캐릭터도 함께 이동합니다. 위에 도착하면 오른쪽 절벽으로 건너갈 수 있습니다.
엘리베이터의 긴 덩굴과 발판 그림은 같은 거리만큼 통째로 이동합니다.
가로로 놓인 네 덩굴 발판은 색 부여 없이 항상 밟을 수 있으며, 아래에서 점프로 통과하고 S로 내려갈 수 있습니다.
R을 누르면 엘리베이터 위치·장치·물·색·캐릭터가 모두 초기화됩니다.
문이 열리는 순간 0.38초 동안 최대 7픽셀의 화면 흔들림이 서서히 줄어들고, 문 양옆에서 회색 돌 조각과 먼지가 퍼집니다.
문이 열린 상태에서는 반복하지 않으며, 다시 닫았다 열면 한 번 더 재생합니다. R로 초기화하면 효과도 사라집니다.
흔들림은 화면에만 적용하며 충돌·캐릭터 위치는 유지합니다. 클릭 좌표와 충돌 범위 표시는 흔들린 화면에 맞춥니다.
